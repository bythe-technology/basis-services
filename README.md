# Basis Services

Official landing page for Basis Services, a professional cleaning company serving Los Angeles and surrounding areas.

## Included

- Responsive English-language landing page
- Home, Airbnb, deep cleaning, and hotel services
- Authentic Basis Services work photos and official brand logo
- WhatsApp quote flow with prefilled customer details
- Phone, email, Instagram, and service-area contact details
- SEO and social-sharing metadata

## Local development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production check

```bash
pnpm lint
pnpm build
```

Built with Next.js, TypeScript, and React. Deployment and custom-domain configuration will be completed through Vercel in the next project stage.
